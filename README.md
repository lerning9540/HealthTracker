# ระบบคัดกรองสุขภาพชุมชน (ต้นแบบ)

เว็บแอปแบบหน้าเดียว (HTML/CSS/JS ล้วน) สำหรับ อสม. ใช้บันทึกผลคัดกรองความดันโลหิตและน้ำตาลในเลือด และดู Dashboard ภาพรวม รองรับมือถือ

## วิธีเปิด

ดับเบิลคลิก `index.html` เพื่อเปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## โครงสร้างโฟลเดอร์

```
web/
├── index.html      หน้าหลัก (Dashboard + ฟอร์มคัดกรอง)
├── css/
│   └── style.css   สไตล์ทั้งหมด (responsive ที่ 1000px / 860px / 600px)
└── js/
    ├── seed.js     ข้อมูลตัวอย่าง (mockup) ใช้เมื่อยังไม่มีข้อมูลในเบราว์เซอร์
    └── app.js      ตรรกะ: บันทึก, คำนวณ BMI, เกณฑ์ผลคัดกรอง, render Dashboard
```

## การเก็บข้อมูล

- ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์ คีย์ `screening_records_v1`
- ยังไม่มี backend หรือฐานข้อมูลจริง
- เคลียร์ข้อมูลทดลอง: เปิด DevTools → Application → Local Storage → ลบคีย์นั้น แล้วรีเฟรช

## เกณฑ์ผลคัดกรองเบื้องต้น

| ระดับ | เงื่อนไข |
| --- | --- |
| ปกติตามเกณฑ์ | ความดัน < 140/90 และน้ำตาล < 126 |
| ต้องประเมินเพิ่มเติม | ความดัน ≥ 140/90 หรือน้ำตาล ≥ 126 |
| ควรส่งต่อบุคลากรทางการแพทย์ | ความดัน ≥ 160/100 หรือน้ำตาล ≥ 200 |

ผลนี้เป็นเพียงการคัดกรองเบื้องต้น ไม่ใช่การวินิจฉัยโรค ควรให้บุคลากรทางการแพทย์ประเมินตามแนวทางของหน่วยบริการ

## การพัฒนาต่อ

- เชื่อมต่อ backend/ฐานข้อมูลจริง แทน localStorage
- หน้ารายละเอียดของแต่ละคน และหน้าทะเบียนประชาชน (ตอนนี้เป็น placeholder)
- ยืนยันเกณฑ์ผลกับแนวทางจริงของหน่วยบริการ

## การแจ้งเตือนทางอีเมล
- ผลสีส้มหรือสีแดงจะส่งเมลไปยังอีเมลที่ตั้งไว้ในหน้าผู้ดูแลระบบ
- ตั้งค่า Apps Script ตามคำอธิบายในไฟล์ `apps-script/Code.gs`
- เมลส่งจากบัญชี Google ที่ deploy สคริปต์ และส่งได้ประมาณ 100 ฉบับต่อวันสำหรับบัญชีทั่วไป
